# Marketing Cloud Script Snippets

A small historical collection of Salesforce Marketing Cloud examples using AMPscript, Server-Side JavaScript, HTML email fragments, and browser-side JavaScript.

## Contents

- Data Extension lookup and ordered-offer examples
- Dynamic email content blocks
- A Server-Side JavaScript web-form handler
- A browser test for posting form data
- Utility snippets for producing inline email HTML

## Usage

These files are snippets rather than a standalone application. Review and adapt them inside the appropriate Marketing Cloud content, CloudPage, or email context.

## Security and privacy

The examples include historical endpoint URLs, sample profile data, permissive CORS, and organization-specific Data Extension names. Replace all example values and perform a privacy and security review before reuse. Do not deploy the snippets unchanged.

## Status

Historical reference material last developed in 2017. APIs, product terminology, and recommended Marketing Cloud practices may have changed.
